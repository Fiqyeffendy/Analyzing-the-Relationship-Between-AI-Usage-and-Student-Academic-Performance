# Analyzing-the-Relationship-Between-AI-Usage-and-Student-Academic-Performance
SQL and Power BI dashboard project analyzing student AI usage, GPA increase, AI dependency, and skill retention.

## Tools
- PostgreSQL
- DBeaver
- Power BI

## Dataset
The dataset contains student-level information such as:
- major_category
- weekly_genai_hours
- pre_semester_gpa
- post_semester_gpa
- perceived_ai_dependency
- skill_retention_score

## Analysis Questions
1. Which major category has the highest average AI usage?
2. Which major category has the highest average GPA increase?
3. Does higher AI usage relate to higher AI dependency?
4. How does AI usage relate to skill retention score?

## Dashboard Preview
![Dashboard Preview](dashboard/dashboard_page_1.png)

## Key Insights
- STEM has the highest average AI usage.
- STEM also has the highest average GPA increase.
- Higher AI usage is associated with higher AI dependency score.
- Medium AI usage shows the highest skill retention score.

## Notes
AI Dependency Score uses a 1–10 scale. Higher score means higher dependency on AI.

## Limitations
This analysis shows relationships between variables, but it does not prove direct causation.
